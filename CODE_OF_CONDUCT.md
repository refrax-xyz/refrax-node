# Code of conduct

Be useful and be decent.

- Discuss code and ideas, not people. Assume good faith.
- No harassment, insults, or discrimination of any kind, in any project space.
- No promotion, price talk or financial advice in issues and pull requests. This repository is about the
  software.

Maintainers may edit or remove comments and block people who don't follow this. Report problems
privately to the maintainers through GitHub.
